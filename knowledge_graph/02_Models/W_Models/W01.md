# W01 — Solar Irradiance Model

> **Status: draft-for-review** (KG sprint 2, 2026-10-23). Reviewed against the ML-KG-04 fields; not `specified` until the owner has reviewed it (MLM SPECS2 §12). Closes SG-W01-1 (plane-of-array transposition; `G_reflected` defined, 0 by default per OD-112) and SG-W01-2 (ensemble members clipped at 0: **owner instruction of 2026-10-23, superseding OD-113** and library D-20's "no clamp"). Items marked **OWNER DECISION** are proposals; see REVIEW.md.

## Purpose
Estimates the solar irradiance on the plane of a PV array or glazed surface (G_POA, W/m²) for a site and time step, from the NWP direct and diffuse irradiance and the sun's position, and gives its forecast uncertainty as an ensemble and p10/p50/p90 quantiles. Primary input to [[R01]] (PV generation), [[T04]] (solar gain for [[T01]]) and [[W14]] (joint weather scenarios).

## Layer
**Stochastic** — outputs a probability distribution over G_POA, not a point estimate. Quantiles (p10/p50/p90) are passed to the determinisation bridge [[C03]]; the members feed [[W14]] and C03's ensemble mode.

---

## Formula

### LaTeX
**Angle of incidence** on a surface of tilt β and azimuth γ (azimuths from north, 180° = south, as DS-PV), sun at zenith θ_z and azimuth γ_s:
$$\cos\theta_{AOI} = \cos\theta_z \cos\beta + \sin\theta_z \sin\beta \cos(\gamma_s - \gamma)$$

**Plane-of-array irradiance** (isotropic sky, Liu & Jordan):
$$G_{POA} = \underbrace{G_{DNI}\,\max(0, \cos\theta_{AOI})}_{G_{beam}} + \underbrace{G_{DHI}\,\frac{1+\cos\beta}{2}}_{G_{sky}} + \underbrace{\rho_g\, G_{GHI}\,\frac{1-\cos\beta}{2}}_{G_{reflected}}, \qquad G_{GHI} = G_{DNI}\cos\theta_z + G_{DHI}$$
with $G_{POA} = 0$ when $\cos\theta_z \le 0$ (sun below the horizon). Default ρ_g = 0, so $G_{reflected} = 0$ (OD-112).

**Cloud attenuation** (clear-sky input mode only, see OWNER DECISION W01-2):
$$G_{POA,cloud} = G_{POA} \times (1 - k_{cloud}\, N/8)$$

**Ensemble**, members ω = 1…N, clipped at zero:
$$G_{POA}^{(\omega)}[t] = \max\left(0,\; G_{POA,det}[t] + \sigma_{irr}[t]\, z^{(\omega)}[t]\right), \qquad z \sim \mathcal{N}(0,1)$$
and $p_q$ = the type-7 sample quantile (Hyndman & Fan 1996) of the clipped members, q ∈ {0.10, 0.50, 0.90}. Because the clip is monotone, each quantile equals max(0, quantile of the unclipped members).

### Description
The old formula, $G_{DNI}\cos\theta_z + G_{DHI}$, is the irradiance on a *horizontal* surface (GHI), not on the array; it had no tilt or orientation, and $G_{reflected}$ appeared in the LaTeX but was never defined (SG-W01-1). W01 now transposes onto the array: the direct beam is scaled by the cosine of the angle between the sun and the panel's normal (zero when the sun is behind the panel), the diffuse sky is taken as uniform, so a tilted panel sees the fraction (1 + cos β)/2 of it, and the ground reflects ρ_g of the horizontal irradiance onto the fraction (1 − cos β)/2 that faces the ground. With β = 0 the formula reduces exactly to the old one (TV-W01-1). The reflected term is defined but off by default (ρ_g = 0), per OD-112. Forecast uncertainty is added as Gaussian noise with the NWP spread, as before, but members are then clipped at 0, because irradiance cannot be negative (SG-W01-2; owner instruction of 2026-10-23); W14 clips its own G_POA marginal at 0 too, so the two are consistent.

### Python Pseudocode
```python
import numpy as np

def w01_irradiance(G_DNI, G_DHI, theta_z, gamma_s, tilt, azimuth, sigma_irr,
                   rho_g=0.0, mode="all_sky", oktas=None, k_cloud=0.11,
                   n_ensemble=50, seed=None):
    """All arrays shape (T,). Angles in degrees, azimuths from north (180 = south).
    G_DNI, G_DHI, sigma_irr in W/m2. mode: 'all_sky' (NWP irradiance already includes cloud)
    or 'clear_sky' (clear-sky irradiance, attenuated by cloud cover in oktas 0-8)."""
    tz, gs = np.radians(theta_z), np.radians(gamma_s)
    b, g = np.radians(tilt), np.radians(azimuth)
    cos_z = np.cos(tz)
    cos_aoi = cos_z * np.cos(b) + np.sin(tz) * np.sin(b) * np.cos(gs - g)
    G_GHI = G_DNI * cos_z + G_DHI
    G_beam = G_DNI * np.maximum(0.0, cos_aoi)
    G_sky = G_DHI * (1 + np.cos(b)) / 2
    G_refl = rho_g * G_GHI * (1 - np.cos(b)) / 2          # 0 by default (OD-112)
    G_det = G_beam + G_sky + G_refl
    if mode == "clear_sky":
        G_det = G_det * (1.0 - k_cloud * np.asarray(oktas) / 8.0)
    day = cos_z > 0
    G_det = np.where(day, G_det, 0.0)
    sigma = np.where(day, sigma_irr, 0.0)

    rng = np.random.Generator(np.random.PCG64(seed))     # explicit seed (library D-20)
    z = rng.standard_normal((n_ensemble, G_det.shape[0]))
    ens = np.maximum(0.0, G_det + sigma * z)               # clip at 0 (SG-W01-2)
    p10, p50, p90 = np.percentile(ens, [10, 50, 90], axis=0)   # type 7 (linear)
    return {"G_POA_det": G_det, "p10": p10, "p50": p50, "p90": p90, "ensemble": ens,
            "components": {"beam": G_beam, "sky": G_sky, "reflected": G_refl}}
```

## Method
Isotropic-sky transposition of beam and diffuse irradiance onto a tilted surface (Liu & Jordan 1963; Duffie & Beckman 2013, ch. 1–2), the standard first-order model; anisotropic models (Hay–Davies, Perez et al. 1990) are more accurate on clear days (Loutzenhiser et al. 2007) and can replace the sky term later without changing the interface. Forecast uncertainty: additive Gaussian perturbation with the NWP ensemble spread, clipped at zero, so the predictive distribution is a Gaussian censored at 0 (a point mass at 0 when the deterministic value is small). Quantiles by the type-7 rule used throughout the C-series (C03).

## RD Role
Stochastic layer, RD lifecycle step 2. G_POA is a registered RD stimulus (C08-I02); W01 supplies its value and distribution, and C08's ∂Flex/∂G_POA passes through R01 (∂P_PV/∂G_POA) and C01. Within W01, ∂G_POA/∂G_DNI = max(0, cos θ_AOI) and ∂G_POA/∂G_DHI = (1 + cos β)/2, so the same NWP change moves a south-facing tilted array more than a horizontal one in winter. Members clipped at 0 have zero sensitivity to the noise, which keeps night and near-dark steps out of the RD spread that C08 takes from C03's ensemble mode.

---

## Validity Limits
- Isotropic sky underestimates G_POA on clear days for tilted surfaces facing the sun (circumsolar and horizon brightening ignored); errors of several per cent are typical (Loutzenhiser et al. 2007).
- The NWP spread σ_irr is quoted for horizontal irradiance and is applied to G_POA unchanged; the Gaussian error model ignores the skew of irradiance errors. W14 and C03 inherit this.
- Clipping at 0 raises the ensemble mean above G_POA_det when G_POA_det is within about 2σ of 0; use G_POA_det or p50, not the member mean, as the point forecast.
- No shading, soiling or horizon model; a single plane per call (one call per array orientation).
- Clear-sky mode depends on the k_cloud decision (W01-2).

## AI Context
When implementing W01:
- `G_DNI` and `G_DHI` come from `DS-NWP.irradiance_dni` and `DS-NWP.irradiance_dhi` — never estimated internally
- Call [[W08]] first for `theta_z` **and** `theta_az`; take `tilt_deg` and `azimuth_deg` from DS-PV (azimuth from north, 180 = south — the same convention for sun and array)
- Do not apply `k_cloud` to all-sky NWP irradiance (decision W01-2)
- Clip members at 0 before computing quantiles; pass an explicit seed
- Return all outputs as a named dict/struct
