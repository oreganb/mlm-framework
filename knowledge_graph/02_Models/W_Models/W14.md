# W14 — Weather Ensemble Generator

> **Status: draft-for-review** (KG sprint 1, 2026-10-23). Filled to the ML-KG-04 fields; not `specified` until the owner has reviewed it (MLM SPECS2 §12). Closes SG-W14-1 (mlm-library SPEC_GAPS.md; library D-26). Items marked **OWNER DECISION** are proposals; see REVIEW.md.

## Purpose
Generates N joint weather scenarios (trajectories over the horizon for outdoor temperature, plane-of-array irradiance and wind speed) whose marginals match the W-series probabilistic forecasts and which preserve both the correlation between variables and the correlation in time. The scenarios feed [[C03]]'s ensemble (robust) determinisation, where C01 is solved once per member.

## Layer
**Stochastic** — Monte Carlo; output is an ensemble with declared units and a seed for reproducibility.

---

## Formula

### LaTeX
Variables $v = 1..d$ (default $d = 3$: $T_{out}$ °C, $G_{POA}$ W/m², wind m/s), steps $t = 1..T$, members $\omega = 1..N$.

**Correlation structure** (separable, time ⊗ variable):
$$\operatorname{Corr}\left(Z_{t,v}, Z_{t',v'}\right) = R^{time}_{t t'} \cdot R^{var}_{v v'}, \qquad R^{time}_{t t'} = \exp\left(-\frac{|t - t'|\,\Delta t}{\ell}\right), \qquad R^{var} = D^{-1/2}\, \Sigma\, D^{-1/2},\; D = \operatorname{diag}(\Sigma)$$
**Sampling** with $L_t = \operatorname{chol}(R^{time})$, $L_v = \operatorname{chol}(R^{var})$, $E^{(\omega)} \in \mathbb{R}^{T\times d}$ i.i.d. $\mathcal{N}(0,1)$:
$$Z^{(\omega)} = L_t\, E^{(\omega)}\, L_v^{\top}$$
**Marginal transform** (Gaussian copula):
$$w^{(\omega)}_{t,v} = F^{-1}_{t,v}\left(\Phi\left(Z^{(\omega)}_{t,v}\right)\right)$$
which for Gaussian marginals $\mathcal{N}(\bar w_{t,v}, s^2_{t,v})$ is
$$w^{(\omega)}_{t,v} = \bar w_{t,v} + s_{t,v}\, Z^{(\omega)}_{t,v}$$
(the previous note's $\mathbf{w}^{(\omega)} = \bar{\mathbf{w}} + L\boldsymbol\epsilon^{(\omega)}$, now with time structure and per-step scale).

### Description
Each member is built from independent standard-normal draws, which are correlated twice: across variables with the cross-variable correlation implied by the NWP covariance Σ (e.g. sunnier hours are warmer in summer), and across time with an exponential correlation of length ℓ (an error at 10:00 is likely to persist at 10:15). The correlated normals are then mapped onto each variable's own forecast distribution, step by step, so every member is consistent with the W01/W02/W03 forecasts while the joint structure is preserved. This is the Gaussian-copula scenario method of Pinson et al. (2009). The previous note had Σ across variables only, "various" units and an N×T output for d variables (SG-W14-1); the output is now N×T×d with declared variable order and units.

### Python Pseudocode
```python
import numpy as np
from scipy.stats import norm

VARS = (('T_out', 'degC'), ('G_POA', 'W/m2'), ('wind', 'm/s'))

def w14_ensemble(marginals, Sigma_var, dt_h=0.25, ell_h=6.0, N=50, seed=None):
    """marginals[v]: per-step inverse CDFs (or (mean, sd) arrays, Gaussian) for each variable;
    Sigma_var: d x d NWP covariance; seed: required integer (reproducibility)."""
    if seed is None:
        raise ValueError("explicit integer seed required")
    T, d = marginals.n_steps, len(VARS)
    t = np.arange(T) * dt_h
    R_time = np.exp(-np.abs(t[:, None] - t[None, :]) / ell_h)
    sd = np.sqrt(np.diag(Sigma_var)); R_var = Sigma_var / np.outer(sd, sd)
    L_t, L_v = np.linalg.cholesky(R_time), np.linalg.cholesky(R_var)
    rng = np.random.Generator(np.random.PCG64(seed))
    E = rng.standard_normal((N, T, d))
    Z = np.einsum('ij,njk,lk->nil', L_t, E, L_v)          # N x T x d
    U = norm.cdf(Z)
    Omega = np.empty_like(Z)
    for v in range(d):
        Omega[:, :, v] = marginals.ppf(v, U[:, :, v])       # per step, per variable
    return {'Omega_w': Omega, 'vars': VARS, 'seed': seed}
```

## Method
Monte Carlo scenario generation with a Gaussian copula (Pinson et al. 2009): marginal predictive distributions per variable and step, joined by a multivariate normal dependence structure whose temporal part is an exponential covariance, estimated from recent forecast errors. Cholesky factorisation for correlated sampling; separable (Kronecker) space-time correlation keeps the factorisation at the cost of two small matrices. Ensemble copula coupling (Schefzik et al. 2013) is the established alternative when a raw NWP ensemble with its own dependence is available.

## RD Role
Stochastic layer, RD lifecycle step 2. Each member is a joint stimulus scenario; C01 solved per member (C03 ensemble mode) gives a sample of RDs, whose spread C08 uses as the RD's uncertainty (library D-12). Preserving the joint and temporal structure matters for RD because the same flexibility depends on several weather inputs at once (PV through G_POA, heating through T_out) and on their persistence over the horizon.

---

## Validity Limits
- Gaussian copula: tail dependence (joint extremes) is underrepresented; for storm or extreme scenarios use W-series extreme models.
- Separable correlation and a single ℓ for all variables.
- Marginals must be calibrated (W01/W02/W03); W14 does not correct them.
- Reproducible only with the same seed, generator and numpy version (stream stability across numpy versions is not guaranteed; test vectors below do not depend on it).
