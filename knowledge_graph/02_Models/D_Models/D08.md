# D08 — Model Drift Detection & Retraining Trigger

> **Status: specified** (owner review 2026-10-23; drafted in KG sprint 1). Filled to the ML-KG-04 fields (MLM SPECS2 §12). Closes SG-D08-1 and the D08 part of SG-LAYER-1 (mlm-library SPEC_GAPS.md; library D-32). Owner decisions are recorded in REVIEW.md.

## Purpose
Watches the prediction errors of every monitored model and raises `drift_flag` when their mean shifts, upward or downward, beyond what normal variation explains, so that the model is retrained ([[F01]], [[F02]]) before its outputs, and the RDs built on them, degrade. It is RD lifecycle step 7 (feedback).

## Layer
**AI/ML** (D-series quality and feedback). The detector is a statistical process-control chart; its "training" is the estimation of the in-control error mean and spread from a reference period, declared below (ML-LIB-02).

---

## Formula

### LaTeX
**Monitoring samples:** the model's mean error per monitoring interval $\Delta_{mon}$ (default 1 day),
$$\bar e_n = \frac{1}{|I_n|}\sum_{t \in I_n} \left(\hat y_t - y_t\right)$$
**Standardisation** against the reference period $R$ (the 30 days after the model's last (re)training):
$$z_n = \frac{\bar e_n - \mu_0}{\sigma_0}, \qquad \mu_0 = \operatorname{mean}_{n \in R}\, \bar e_n, \qquad \sigma_0 = \operatorname{sd}_{n \in R}\, \bar e_n$$
**Two-sided tabular CUSUM** (Page 1954):
$$C^{+}_n = \max\left(0,\; C^{+}_{n-1} + z_n - k\right), \qquad C^{-}_n = \max\left(0,\; C^{-}_{n-1} - z_n - k\right), \qquad C^{\pm}_0 = 0$$
$$drift\_flag_n = \left(C^{+}_n > h\right) \lor \left(C^{-}_n > h\right), \qquad h = 5,\; k = 0.5$$
After an alarm: $C^{\pm} \leftarrow 0$; after retraining, $\mu_0, \sigma_0$ are re-estimated on the new reference period.

**Average run length** (Siegmund's approximation, one-sided, for a mean shift $\delta$ in units of $\sigma_0$):
$$ARL(\delta) \approx \frac{e^{-2\Delta b} + 2\Delta b - 1}{2\Delta^2}, \qquad \Delta = \delta - k, \quad b = h + 1.166; \qquad \frac{1}{ARL_{two\text{-}sided}} = \frac{1}{ARL^{+}} + \frac{1}{ARL^{-}}$$

### Description
D08 keeps two running totals of standardised errors: one that grows when errors are persistently higher than in the reference period, one when they are persistently lower. Each step it adds the new standardised error minus an allowance k = 0.5 and floors the total at zero, so random noise keeps the totals near zero while a sustained shift of about one standard deviation accumulates. When either total exceeds h = 5 the model is flagged for retraining. With k = 0.5 and h = 5 a correctly working model raises a false alarm about once every 470 samples, and a one-standard-deviation shift is detected in about 10 samples (TV-D08-1, -2). Errors are first averaged per day, because 15-minute forecast errors are strongly autocorrelated: applied to them directly, the false-alarm rate would be far higher than the run-length calculation assumes, and 470 samples would be under five days. The previous note gave only h = 5.0 and a 30-day window; the CUSUM variant, the reference value k and the standardisation were missing (SG-D08-1).

### Python Pseudocode
```python
import numpy as np

class D08Cusum:
    def __init__(self, ref_errors_daily, k=0.5, h=5.0):
        self.mu0 = float(np.mean(ref_errors_daily))
        self.sd0 = float(np.std(ref_errors_daily))      # population s.d. over the reference days
        if self.sd0 == 0:
            raise ValueError("reference errors have zero spread")
        self.k, self.h = k, h
        self.cp = self.cm = 0.0

    def update(self, errors_in_interval):
        z = (np.mean(errors_in_interval) - self.mu0) / self.sd0
        self.cp = max(0.0, self.cp + z - self.k)
        self.cm = max(0.0, self.cm - z - self.k)
        flag = self.cp > self.h or self.cm > self.h
        direction = 'up' if self.cp > self.h else ('down' if self.cm > self.h else None)
        if flag:
            self.cp = self.cm = 0.0                     # reset after alarm
        return {'drift_flag': flag, 'direction': direction, 'z': z,
                'C_plus': self.cp, 'C_minus': self.cm}
```

## Method
Two-sided tabular CUSUM for a shift in the mean (Page 1954; Hawkins & Olwell 1998), with the reference value k = δ/2 that is optimal for detecting a shift of δ = 1 standard deviation, and the conventional pairing h = 5 for k = 0.5 (Hawkins & Olwell 1998). Run lengths by Siegmund's approximation (Siegmund 1985). ADWIN (Bifet & Gavaldà 2007), named in the previous note, is an established alternative that adapts its window without a reference period; it is not specified here (**Owner decision (approved 2026-10-23)**: CUSUM is the single method; ADWIN is not specified).

## RD Role
RD lifecycle step 7 (feedback: "update trust, weights, and policies"). D08 does not estimate RD. A drift flag on a model lowers the confidence of every RD built on that model's outputs (through `d08_quality`) and, through FLEXUS G-5 (model retraining), moves the scope to advisory until the model is retrained. D08 can also monitor RD itself: applying the same CUSUM to the residuals of observed versus predicted response detects RD drift (RD-4), which FLEXUS G-2 then acts on.

---

## Validity Limits
- The ARL figures assume independent, roughly normal monitoring samples; daily aggregation helps but does not remove autocorrelation; check the lag-1 autocorrelation of reference-period z (if > 0.3, widen Δ_mon or fit an AR(1) and monitor its residuals).
- Detects mean shifts only; variance changes (a model becoming noisier without bias) need a separate CUSUM on squared standardised errors.
- Needs 30 reference days after each retraining before monitoring is meaningful; during that time the model runs unmonitored by D08 (flag it as such).
- Seasonal models: a reference period in one season can raise alarms in the next without real drift; retraining seasonally resets it.
