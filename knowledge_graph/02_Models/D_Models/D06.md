# D06 — Missing Data Imputation Model

> **Status: draft-for-review** (KG sprint 1, 2026-10-23). Filled to the ML-KG-04 fields; not `specified` until the owner has reviewed it (MLM SPECS2 §12). Closes SG-D06-1 and the D06 part of SG-LAYER-1 (mlm-library SPEC_GAPS.md; library D-34). Items marked **OWNER DECISION** are proposals; see REVIEW.md.

## Purpose
Replaces missing or faulty sensor readings (flagged by [[D04]]) with estimates from the same sensor's nearby readings in time and from comparable sensors nearby in space, with an uncertainty and an `imputed_flag`, so downstream models receive complete series and know which values are not measured. Beyond the maximum gap it falls back to the archetype profile and raises an alert.

## Layer
**AI/ML** — k-nearest-neighbour imputation with distances learned from each sensor's history; returns the imputed value with an uncertainty, which is its ConfidenceObject input (ML-LIB-02).

---

## Formula

### LaTeX
For a missing value $x_{i,t}$ of sensor $i$ at step $t$, candidate neighbours $k$ give predictions $\tilde x_k$ with distances $d_k$, both in the units of $x$:

**Temporal neighbours** (valid readings of sensor $i$ at $t_k$, lag $\ell_k = |t - t_k|$ steps):
$$\tilde x_k = x_{i,t_k}, \qquad d_k = \sqrt{2\hat\gamma_i(\ell_k)}, \qquad \hat\gamma_i(\ell) = \frac{1}{2|P_\ell|}\sum_{(s, s+\ell) \in P_\ell} \left(x_{i,s+\ell} - x_{i,s}\right)^2$$
**Spatial neighbours** (same-type sensors $k$ valid at $t$, offset-corrected):
$$\tilde x_k = x_{k,t} + o_{ik}, \qquad o_{ik} = \operatorname{median}_{s \in 7d}\left(x_{i,s} - x_{k,s}\right), \qquad d_k = \sqrt{\operatorname{mean}_{s \in 7d}\left(x_{i,s} - x_{k,s} - o_{ik}\right)^2}$$
**Estimate** (the previous note's inverse-distance weighting, normalised):
$$\hat{x}_{i,t} = \sum_{k \in \mathcal{K}} w_k\, \tilde x_k, \qquad w_k = \frac{1/d_k}{\sum_{j \in \mathcal{K}} 1/d_j}, \qquad \hat\sigma_{i,t} = \sum_{k \in \mathcal{K}} w_k\, d_k = \frac{|\mathcal{K}|}{\sum_{j \in \mathcal{K}} 1/d_j}$$
where $\mathcal{K}$ is the 3 temporal neighbours with the smallest $d_k$ (lags within the maximum gap) plus the 2 spatial neighbours with the smallest $d_k$. **Fallback:** if $\mathcal{K} = \emptyset$ or the gap exceeds 16 steps, $\hat x_{i,t}$ = archetype profile ([[L12]]) for that hour, with $\hat\sigma$ = the archetype's spread, and an alert.

### Description
Each candidate neighbour is judged by how well it has predicted this sensor in the past, measured in the sensor's own units: for the sensor's own earlier or later readings, the typical change over that lag (from the empirical variogram); for a neighbouring sensor, the typical disagreement after removing its usual offset (a neighbour that always reads 0.8 °C cooler is corrected by 0.8 °C). That makes time and space neighbours comparable, which the previous note left undefined. The three best temporal and two best spatial neighbours are averaged with weights proportional to 1/distance, normalised to sum to one, so the estimate is in the units of x and does not grow with the number or closeness of neighbours (with unnormalised weights, TV-D06-2 gives 284.9 instead of 20.3 °C). The uncertainty is the weighted mean distance, a conservative bound that assumes the neighbours' errors are perfectly correlated. Gaps longer than four hours are filled from the archetype profile with an alert. The previous note's weights were unnormalised, its distance across time and space was undefined, and how the 3 + 2 neighbours are chosen was not said (SG-D06-1).

### Python Pseudocode
```python
import numpy as np

def variogram_rmse(x_hist, lag):
    a = x_hist[lag:] - x_hist[:-lag]
    return np.sqrt(np.nanmean(a**2))                     # = sqrt(2 * gamma(lag))

def d06_impute(i, t, series, neighbours, archetype, gap_steps, online=True, max_gap=16):
    if gap_steps > max_gap:
        return archetype.value(t), archetype.spread(t), 'archetype', True     # alert
    x = series[i]
    # temporal candidates: valid readings within max_gap (past only when online)
    lags = [l for l in range(1, max_gap + 1) if not np.isnan(x[t - l])]
    if not online:
        lags += [-l for l in range(1, max_gap + 1) if t + l < len(x) and not np.isnan(x[t + l])]
    temporal = sorted(((x[t - l], variogram_rmse(x.history_30d, abs(l))) for l in lags),
                      key=lambda c: c[1])[:3]
    # spatial candidates: same-type sensors valid at t, offset-corrected
    spatial = []
    for k in neighbours:
        if np.isnan(series[k][t]):
            continue
        diff = x.history_7d - series[k].history_7d
        o = np.nanmedian(diff)
        spatial.append((series[k][t] + o, np.sqrt(np.nanmean((diff - o) ** 2))))
    spatial = sorted(spatial, key=lambda c: c[1])[:2]
    cands = temporal + spatial
    if not cands:
        return archetype.value(t), archetype.spread(t), 'archetype', True
    vals = np.array([c[0] for c in cands]); d = np.array([c[1] for c in cands])
    w = (1 / d) / np.sum(1 / d)
    return float(w @ vals), float(w @ d), 'knn_idw', False   # x_hat, sigma_hat, method, alert
```

---

## Method
Inverse-distance weighted interpolation (Shepard 1968) applied as k-nearest-neighbour imputation (Troyanskaya et al. 2001), with weights normalised to sum to one. Distances are empirical prediction errors: the temporal one is the square root of twice the empirical semivariogram at the lag (Cressie 1993), the spatial one is the offset-corrected RMS difference over seven days; both are in the units of the variable, so temporal and spatial neighbours can be ranked and weighted together. The previous note also named the EM algorithm and forward-fill with decay; neither is specified here (**OWNER DECISION**: drop them; forward-fill is the special case of one temporal neighbour at lag 1, and the archetype fallback covers long gaps).

## RD Role
AI/ML layer, confidence side of RD (Bible §25, D-series "RD confidence weighting"). Imputed stimulus or response values carry `imputed_flag` and σ̂; an RD estimated over a window containing imputed values must record it, and observed RD routes in [[C08]] should exclude imputed samples from the stimulus/response pairs (imputed data would otherwise manufacture a response that was never measured).

---

## Validity Limits
- Assumes local stationarity over the history windows (variogram and offsets); after an equipment change, reset the histories.
- σ̂ is an upper bound under perfectly correlated neighbour errors; it overstates uncertainty when neighbours are independent.
- Spatial neighbours must be the same quantity and comparable placement (indoor with indoor, south-facing PV with south-facing PV).
- Maximum gap 4 h; longer gaps use the archetype and are not suitable as training data.
