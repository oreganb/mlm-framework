# P07 — Response Derivative KPI Model

> **Status: draft-for-review** (KG sprint 1, 2026-10-23). Filled to the ML-KG-04 fields; not `specified` until the owner has reviewed it (MLM SPECS2 §12). Closes SG-P07-2, takes the MLM SPECS2 **LO-09** recommended position on SG-P07-1, and records the RD-1..RD-10 KPI set (KG-CR-04) with the library's estimators (D-15). Items marked **OWNER DECISION** are proposals; see REVIEW.md.

## Purpose
Reports how responsive a community (portfolio of buildings and assets) is to a given stimulus, as a single KPI tracked over time: a capacity-weighted portfolio RD with its uncertainty, plus the RD KPI set RD-1..RD-10 (Bible §28). It is a **reporting** model for research and community dashboards ([[P08]]). Operational portfolio RD used for offers and dispatch is FLEXUS's FX-RD-02 (confidence-weighted, incoherence-penalised), not P07 (LO-09).

## Layer
**RL/Q-Learning** (P-series KPI in the decision layer). Deterministic given its inputs.

## Formula

### LaTeX
For $N$ RDs $RD_i$ (W per stimulus unit) that share one stimulus, response, direction and semantic class, with rated powers $P_{rated,i}$ (W):
$$RD_{portfolio} = \sum_i w_i \, RD_i, \qquad w_i = \frac{P_{rated,i}}{\sum_j P_{rated,j}}$$
(unchanged), and two companion quantities:
$$RD_{total} = \sum_i RD_i, \qquad \widetilde{RD}_{portfolio} = \frac{RD_{total}}{\sum_j P_{rated,j}} = \sum_i w_i \frac{RD_i}{P_{rated,i}}$$
**Uncertainty** (not assuming independence):
$$SE(RD_{portfolio}) = \sqrt{\mathbf{w}^{\top} \Sigma\, \mathbf{w}}, \qquad \Sigma_{ij} = \rho_{ij}\, s_i\, s_j, \qquad \rho_{ij} = 1 \text{ unless an estimate is supplied}$$
With $\rho_{ij} = 1$, $SE = \sum_i w_i s_i$ (the upper bound for non-negative correlations).
**Coherence (reported, not penalised):**
$$V_{w} = \sum_i w_i \left(\frac{RD_i}{P_{rated,i}} - \widetilde{RD}_{portfolio}\right)^2$$

### Description
P07 averages the asset RDs with weights proportional to rated power, so large assets count more. $RD_{portfolio}$ is a "typical RD per asset" in W per unit stimulus. $RD_{total}$ is the community's combined response to a stimulus that all assets see at once (e.g. a community price); $\widetilde{RD}_{portfolio}$ divides it by total capacity so communities of different sizes can be compared, and equals the capacity-weighted mean of each asset's RD per rated watt. RDs can only be added when they are the same derivative: same stimulus and unit, same response, same direction and same semantics (SG-P07-2); otherwise P07 refuses. The uncertainty does not treat assets as independent (FX-RD-02 forbids it): by default the asset RDs are assumed perfectly correlated, the conservative choice, unless a measured correlation is supplied. $V_w$ shows how differently the assets respond per rated watt; P07 reports it but does not penalise the KPI with it, because FX-RD-02's coherence penalty belongs to FLEXUS (LO-09).

### Python Pseudocode
```python
import numpy as np

def p07(rds, P_rated, s, rho=None):
    """rds: list of RD records (value, stimulus, unit, response, direction, semantics)."""
    keys = {(r.stimulus, r.unit, r.response, r.direction, r.semantics) for r in rds}
    if len(keys) != 1:
        raise ValueError("P07 aggregates one stimulus/response/direction/semantics only")
    rd = np.array([r.value for r in rds]); P = np.asarray(P_rated, float); s = np.asarray(s, float)
    w = P / P.sum()
    C = np.ones((len(rd), len(rd))) if rho is None else np.asarray(rho)
    Sigma = np.outer(s, s) * C
    rd_norm = rd / P
    port_norm = rd.sum() / P.sum()
    return {'RD_portfolio': w @ rd, 'SE': float(np.sqrt(w @ Sigma @ w)),
            'RD_total': rd.sum(), 'SE_total': float(np.sqrt(Sigma.sum())),
            'RD_portfolio_norm': port_norm,
            'coherence_var': float(w @ (rd_norm - port_norm) ** 2)}
```

### RD KPI set RD-1..RD-10 (KG-CR-04)

|---|---|---|---|
| RD-1 RSI | ∂R/∂X | OLS slope of R on X over the window | — |

| RD-3 RStI | Var(∂R/∂X) | population variance of RD samples (ddof = 0) | — |
| RD-4 RDI | d/dt(∂R/∂X) | OLS slope of RD against time (per second) | — |

| RD-8 FEK | ∂F/∂I | OLS slope, literal (not a relative elasticity) | — |
| RD-9 RSI-R | ∂Rb/∂A | OLS slope, literal | — |
| RD-10 ARC | 1 − Var(∂R_i/∂X) | literal, population variance across members | not dimensionless (SG-KPI-10); open |

## Method
Capacity-weighted aggregation (the previous note's formula). Uncertainty by propagation of correlated standard uncertainties through a linear function (JCGM 100:2008, the GUM, §5.2: combined standard uncertainty for correlated input quantities). RD KPI estimators as in mlm-library D-15 (ordinary least squares and population variance).

## RD Role
Community-scale expression of RD for reporting (Bible §28, KG-CR-04). P07 consumes synthesised RDs from [[C08]] and never feeds them back into dispatch or governance; operational portfolio RD is FLEXUS FX-RD-02 (LO-09). Every aggregate is per stimulus/response pair and per fragment (FX-RD-04).

---

## Validity Limits
- Only RDs with identical stimulus (name and unit), response, direction and semantic class; mixed inputs are refused.
- RD_total is meaningful only when every asset sees the same stimulus at the same time (a common price or signal); for asset-local stimuli (each building's own T_in) report RD_portfolio only.
- SE with ρ = 1 is an upper bound for non-negative correlations; it can understate if errors are negatively correlated (not expected for a shared stimulus).
- RD-1..RD-10 inherit the open points SG-KPI-5, -7, -10.
